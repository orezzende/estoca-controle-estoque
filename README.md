# Estoca · Controle de Estoque Industrial

Painel de controle de estoque multiunidade para um parque industrial. Projeto de portfólio com dados simulados.

**Demo:** https://orezzende.github.io/estoca-controle-estoque/

## Funcionalidades

- Indicadores de SKUs ativos, itens abaixo do mínimo, transferências em trânsito e valor em estoque
- Gráficos de saldo por categoria e filtro por unidade fabril (7 unidades simuladas)
- Lista de itens críticos com status (crítico/atenção) e histórico de movimentações (entrada, saída, transferência)
- Visão por armazém com ocupação

## Tecnologias

HTML, CSS, JavaScript, Chart.js

## Como usar

Abra a demo ou o `index.html` no navegador.

Também dá para baixar o repositório e abrir o `index.html` direto no navegador, sem instalar nada.

## Observações

Todos os dados (produtos, quantidades, valores e unidades) são fictícios. O Chart.js é carregado por CDN.
